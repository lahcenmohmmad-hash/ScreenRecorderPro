# SpellMaster – متقن الإملاء

تطبيق لتدريب إملاء الكلمات الإنجليزية، يعمل بدون إنترنت، مع نطق صوتي وتكرار متباعد ذكي.

## التثبيت على الهاتف
1. افتح الرابط: https://lahcenmohmmad-hash.github.io/ScreenRecorderPro/ (مرة واحدة بالإنترنت).
2. من قائمة Chrome اختر **Install app / تثبيت التطبيق** (أو إضافة إلى الشاشة الرئيسية).
3. بعدها يعمل بالكامل بدون إنترنت.

## النطق بدون إنترنت
يستخدم صوت الهاتف الإنجليزي. على أندرويد: الإعدادات ← تحويل النص إلى كلام ← Google ← تثبيت بيانات الصوت ← English.
